# Build brief — read this before writing any code

## Stack
Vite + React + Tailwind + Framer Motion. No other dependencies unless I ask.

## Before you write code
Ask me three questions and wait for answers:
1. What does this business actually sell?
2. Who buys it, and what do they already know when they land here?
3. What is the ONE action this page should produce?

Then state, in four lines: the palette, the type pairing, the layout structure,
and the one signature element. Only then write code.

## Ground the design in the subject
Pull the visual language from the business's own world — its materials, its
vocabulary, the documents its buyers already read. A page for a corporate gifting
supplier and a page for a dental clinic should not be able to swap stylesheets.

## The six tells — never ship any of these
These are the six things that make a page read as machine-made. All six are banned.

1. **Cream background + high-contrast serif display + a warm terracotta accent.**
   This exact combination is the single most common AI-page signature. Do not use it.
2. **Near-black background with one bright acid-green or vermilion accent.**
   The second most common. Also out.
3. **Accenting one word in a headline** in italic, bold, or a different colour.
   Write a headline that works without a highlighter.
4. **ALL-CAPS labels**, and any small typographic label floating above a heading.
   If the label carries no information, delete it.
5. **A fade-and-slide-up entrance on every section, and a hover lift on every card.**
   Pick ONE orchestrated moment on the page. Everything else stays still until
   the visitor does something.
6. **A row of big numbers with small labels as the hero treatment**
   (`500+ · 4 years · 100%`). Numbers belong next to the thing they describe,
   not stacked as decoration.

Also avoid `01 / 02 / 03` markers unless the content genuinely is a sequence.

## Typography
One family, or two that are clearly different from each other. Set a real type
scale. Body copy under 80 characters per line. Treat display type as part of the
design, not a container for words.

## Structure carries meaning
Borders, rules, numbering and dividers should encode something true about the
content. If a device is only decoration, remove it.

## Copy
If I have not given you copy, write it — and write it specific. Generic copy makes
a page feel templated faster than generic layout does.

## Accessibility, non-negotiable
Real focus states. Contrast that passes AA. Semantic headings in order. Alt text
on every image. Keyboard-reachable everything.
