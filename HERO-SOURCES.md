# Where to get a hero section that already looks good

## 21st.dev
https://21st.dev — community React + Tailwind components, live previews.
Find a hero you like, copy the code, drop it into `src/`, then tell Claude:

> Replace my hero with the component in src/<file>, keep my copy, and restyle it
> to the palette in CLAUDE.md.

## Motion
Framer Motion is already in the stack. One rule from CLAUDE.md still applies:
**one orchestrated moment**, not an entrance animation on every section.

Good use: the hero assembling once on load.
Bad use: every card fading up as you scroll. That is tell #5.
